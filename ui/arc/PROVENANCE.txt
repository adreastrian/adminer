Registry relative imports are preserved. Local integration changes:
- select/select.tsx stops Escape propagation from the popup so Adminer's body
  handler cannot also close the mobile sidebar. Radix still dismisses the popup
  and restores trigger focus.
- combobox/combobox.tsx adds opt-in allowCustomValue for native input[list]
  fields. Typed text remains the value even without a matching suggestion.
  Editable text skips selection animation and resyncs its filter on native reset.
  Disabled or read-only fields close open menus and cannot select or clear.
  Empty values have no clear button. Blur closes the menu and forwards onBlur.
  Outside-pointer detection uses composedPath so shadow-root options stay usable.
  Escape stops propagation while the menu is open, preserving the mobile sidebar
  and input focus when Adminer's body key handler runs.
- combobox/combobox.module.css uses border-box sizing so the control height token
  includes its border, matching Select and native fields.
Other Adminer adapters live outside arc/ in ui/main.tsx and ui/bridge.css.
Build: npm ci && npm run typecheck && npm run build
Production: assets/arc-ui.js and assets/arc-ui.css are served locally by PHP.
